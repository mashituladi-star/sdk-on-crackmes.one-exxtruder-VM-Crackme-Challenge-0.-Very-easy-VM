📖 Overview / Обзор
Complete SDK for analyzing custom VM-based crackme challenges.
Полный SDK для анализа crackme-задач с пользовательской виртуальной машиной.

✨ Features / Особенности
VM Emulator: Full 8-bit VM emulation (256 bytes memory)
Эмулятор VM: Полная эмуляция 8-битной VM (256 байт памяти)

40+ Instructions: Arithmetic, logic, shifts, jumps, I/O
40+ инструкций: Арифметика, логика, сдвиги, переходы, ввод/вывод

Disassembler: Convert bytecode to readable assembly
Дизассемблер: Преобразование байткода в читаемый код

Test Suite: 15 comprehensive tests
Тесты: 15 всесторонних тестов

Examples: Ready-to-use crackme analysis examples
Примеры: Готовые примеры для анализа crackme

🏗️ VM Architecture / Архитектура VM
Specification	Value
Memory Size	256 bytes
Stack Size	34 bytes
Instructions	1-3 bytes each
Registers	8-bit with flags (Z,S,C,V)
